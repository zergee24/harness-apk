# 0.2.5 已知问题与回滚说明（测试通道预验证版）

> 本版为 0.2.5 P0 收口 + P1 工作 Git 闘环核心的**测试通道预验证版**，用于真机回归；正式通道尚未发布。随 `product-plan.md` v4 P3 硬发布门禁。
>
- versionName：`0.2.5`（test 通道显示 `0.2.5-debug`）
- versionCode 基础：`2000000`（实际构建号 = 基础 + GitHub run number）

## P0 代码缺口闭合

1. **写回后 Git 状态静默刷新**：apply 成功后投递 `projectContentInvalidation`，项目工作台收到后刷新 Git 状态；APPLIED/部分应用卡新增"Git 工作区已更新（未提交）"提示。
2. **项目上下文常驻 Chip**：项目会话时 ChatScreen 输入栏显示当前项目名 Chip，点击进 SessionConfigDialog；生活会话不显示。
3. **安装取消反馈**：`ApkInstaller` 改用 `rememberLauncherForActivityResult(StartActivityForResult())`，取消/失败显示"安装未完成，可点继续安装重试"，成功显示"安装完成"。
4. **状态栏图标随主题联动**：`ModeTheme` 用 `WindowInsetsControllerCompat` 按 `normalizeThemeSource(mode)` 翻转状态栏/导航栏图标（生活暖浅→深色图标，工作/我的深色→浅色图标），不再跟随系统深色模式。

## P1 工作 Git 闭环核心

5. **"待提交"白名单提交**：项目工作台 Git tab 新增"待提交(N)"入口，列出"本轮会话已评审并 apply 的写回文件"（由 `container.projectAppliedPaths` 记录、与当前工作区改动取交集），支持逐文件增删行数摘要。
6. **自动预填提交信息**：按改动文件类型推导前缀（全 Markdown → `docs:`，否则 `chore:`）+ 文件数与文件名，预填、可编辑、可一键提交不打字。
7. **只暂存白名单路径**：新增 `GitEngine.stagePathsAndCommit`，只 `git add`/`git rm` 指定路径，**不执行 `git add -A`**；其余工作区改动保持不暂存；已支持删除类变更（文件不存在走 `git rm`）。
8. **提交后推送确认**：提交成功紧接着弹"推送到远端？"，显示分支/领先/落后；落后（非快进）时禁用推送并提示"去桌面处理"，**绝不自动 pull/merge**。
9. **改动统计**：新增 `GitEngine.diffStat`，按文件给出相对 HEAD 的增删行数。

## 安全约束（P1 已落地）

- 禁止强推、自动解冲突、`git reset --hard`、amend；非快进不自动拉取。
- 一次提交只纳入本轮已 apply 的写回文件白名单；其余不暂存。

## 待真机回归（发布前必须）

- P0：状态栏图标对比度（生活暖浅 / 工作·我的深色）；安装取消/失败/成功反馈文案与目标机型结果码语义；写回后 Git 刷新在"会话与工作台同活"场景；三 Tab 切换/双主题/重启恢复/生活会话列表无项目分组。

## 已知限制

- 提交后 `gitStatus` 的 aheadCount 可能在推送确认弹窗渲染瞬间略滞后（refreshGitState 异步），behindCount 不受影响，推送启用判断安全。
- 回滚方式：无应用内降级，侧载旧 prod 包（同包名、同通道固定签名）；真机回归未完成前不合并至 main / 不发正式通道。
