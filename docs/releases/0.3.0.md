# 0.3.0 M2 跨端任务发布候选说明

> 本文对应“一个任务跨手机与 Mac 连续运行”M2 发布候选。当前默认 Gradle `versionName` 仍与 `test` 基线保持一致；生成 0.3.0 候选包时显式传 `-PversionNameOverride=0.3.0`，避免在 M1 并行交付期间提前改变公共版本线。

## 主要能力

- Android 项目可绑定 Bridge 提供的 Mac workspace，不要求用户输入路径；发起后原子持久化 Run 和完整命令 Outbox。
- Mac Bridge 以稳定 `commandId/runId/threadId/turnId` 调用 Codex app-server，持久保存 route、命令结果和加密 Logical Event Journal。
- Android 从 Room 恢复 Run、Activity、审批、时间线与同步 cursor；断线后按 contiguous ACK 重放，Gap 时禁用审批并由 Snapshot 对账。
- Life/Work 使用同一 Activity 入口；通知只提供“查看/拒绝/停止”，任何“允许一次”都必须解锁并进入 Run Detail，高风险操作再二次确认。
- Run Detail 提供最近 100 条时间线和向上分页，支持持久化 steer/interrupt；停止请求在 Mac 权威终态到达前不乐观显示“已停止”。
- 完成卡只从结构化 Item、明确 exit code 和 Bridge 的只读 Git inspect 生成文件/测试/Git/遗留证据；缺项显示“未验证”，不采信 Agent 自述。

## 数据与协议升级

- Room：`21 -> 22`，新增 binding、run、event、approval、command outbox、sync cursor 六张表；既有 Context Snapshot V2、搜索、Agent/Wiki 数据必须保留。
- Bridge：state `v1 -> v2` 保留 credential 和 sequence；旧 PendingOutbound 因缺少 Logical Event 身份而清空，并强制 Gap + Snapshot。
- 协议：新增 `run.start/run.steer/run.interrupt/approval.respond` 与 `sync.resume/run.snapshot/event.ack`；副作用命令以持久 command cache 幂等，`UNKNOWN` 不自动重放。

## 已验证

- Android JVM 全量单测与 Debug 构建通过；Room 21 -> 22 文件迁移、Run/Approval 重开、Outbox 重建、Logical Event 去重和 Gap/Snapshot 有自动化覆盖。
- 独立 `HarnessM2Api36` / ADB 5039 / `emulator-15662` 下，320dp、字体 1.3、Activity/Run Detail/审批/恢复设备测试通过。
- 10,000 条 Event 数据集查询最近 100 条的当前模拟器样本 p95 为 9ms，低于 200ms Gate。
- Go 全包 test、race、vet 与 Relay/Bridge build 纳入发布 Gate；详见 M2 验收台账。

## 发布前仍需人工完成

- 目标荣耀真机上的阿里云 Push、锁屏通知、解锁审批、OEM 后台限制与十分钟真实断网恢复。
- 真实 Relay + Mac Bridge + 当前 Codex app-server 的七条黄金链路，记录版本、PID/process epoch、截图和日志。
- test 通道候选安装/升级后再决定是否更新公共默认 versionName 和生产 update manifest；本分支不发布、不推送。

## 已知限制

- `requestUserInput` 首版不会把手机答案伪装为 approval；Run 显示 `WAITING_USER`，保留脱敏证据并提示在 Mac UI 重新发起。
- M2 不提供 `ALLOW_ALWAYS`，不提供手机终端、自动 Commit/Push/Merge，也不声称 Mac UI 能接管 Bridge-owned 活跃 Turn。
- “沉淀到项目”完整闭环属于 M3，M2 不展示不可用按钮。

## 回滚

- APK：同通道、同签名侧载上一稳定包；Room 22 是前向迁移，回滚包必须能读取版本 22，不能以清空应用数据作为标准回滚步骤。
- Bridge：升级前停止 launch agent 并备份完整 `~/.harness-remote`；只允许回滚到兼容 state v2 的 Bridge build，完整恢复目录，不单独删除 Journal/commands/routes。
- Relay：继续保留 opaque ciphertext 和现有 credential state；若回滚 Relay，不旋转或删除 Bridge/设备凭据，除非明确执行 host recovery 并接受全部手机重新配对。
