# 0.2.4 已知问题与回滚说明

> 回溯补齐（2026-08-04）。本文为 `product-plan.md` v4 P3 硬发布门禁的首份产物，0.2.4 已先行发布 test/prod，故回溯补写。
>
- versionName：`0.2.4`（test 通道显示 `0.2.4-debug`）
- versionCode 基础：`2000000`（实际构建号 = 基础 + GitHub run number，按 `release-hosting.md` 版本策略）
- 设计依据：`docs/superpowers/specs/2026-08-02-tab-navigation-design.md`

## 本版本主要变更

- 一级导航由 0.2.3 的"双面板 Pager + 顶部模式 Tab + 滑动"重构为**底部三 Tab：生活 / 工作 / 我的**。
- 生活 Tab 只显示普通会话（`projectId == null`），移除"按项目分组"视图，UI 上隐藏"默认生活项目"层级。
- 工作 Tab = 远程控制入口卡片 + 项目列表 + 项目工作台。
- "我的" Tab = 设置聚合页（内嵌 SettingsScreen），顶栏设置按钮移除。
- 双主题映射：生活=暖浅；工作、我的=深科技（300ms 过渡保留）。
- 模式持久化迁移：旧值 LIFE→LIFE、WORK→WORK，新增 ME。

## 已知问题（待 0.2.5 修复，见 `product-plan.md` P0）

1. **系统状态栏图标对比度未随主题联动**：生活=暖浅时状态栏图标在浅色系统下清晰；工作/我的=深色 + 浅色系统下，状态栏图标仍为深色、对比度不足（`Theme.kt`/`MainActivity.kt` 未用 `WindowInsetsControllerCompat`，仅靠 `values/values-night`）。
2. **写回项目后 Git 状态不自动刷新**：apply 成功只刷新会话内 deliverables，需手动进 Git tab 才读 `git status`。
3. **当前项目无常驻 Chip**：项目名仅在工作首页标题与 SessionConfigDialog 出现，会话输入栏/列表无提示。
4. **APK 安装取消无反馈**：`ApkInstaller` fire-and-forget，系统安装器取消后 App 内无提示。

## 回滚说明

- App **无应用内降级**，自更新器只前进（`forceUpdate` 仅强制升级，不降级）。
- 回滚方式 = **侧载旧 prod 包**：从 OSS 历史目录取上一正式版本 APK，手动安装覆盖。
  - 历史版本目录默认保留：`https://www.zerg.work/harness-apk/prod/releases/<versionCode>/app-release.apk`
  - 同包名覆盖安装要求签名一致（test/prod 通道各自固定签名，不可跨通道覆盖）。
- 数据兼容：0.2.4 的模式持久化迁移为单向加项（LIFE/WORK 保留语义，新增 ME），降级到 0.2.3 时若已用过"我的" Tab，旧版会把未知值回落为默认 LIFE（见 `HomeModeStore.migrateStoredMode` 的 null/未知→LIFE 处理），不会崩溃。

## 强制更新门禁

- 已确认 updater 支持 `forceUpdate = currentVersionCode < manifest.minSupportedVersionCode`（`UpdateRepository.kt`）。
- 发布前需确认 prod `update.json` 的 `minSupportedVersionCode` 已按策略声明，确保坏版本可被强制升级拦截。
