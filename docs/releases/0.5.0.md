## 家庭交付一期：`.hconfig` 配置包与生活简洁模式

计划与决策记录见 [docs/superpowers/plans/2026-09-03-life-family-config-phase-1.md](../superpowers/plans/2026-09-03-life-family-config-phase-1.md)。

1. **配置包导出**：我的 → 配置包，勾选模型配置（含 API Key）、语音凭证、联网搜索、简洁模式，口令二次加密（PBKDF2 310k + AES-256-GCM），有效期 12/24/72 小时且入 AAD 防篡改，生成后系统分享发送。
2. **配置包导入**：微信「用其他应用打开」或我的 → 配置包 → 导入；口令解密 → 预览（不显示 Key）→ 应用；provider 按 name+baseUrl upsert、首个自动设为默认；完成后回生活页展示一次性引导。过期拒绝并提示检查系统时间；口令错误与篡改同文案。
3. **Keystore 软件回退**：`ResilientStringCipher` 覆盖 provider / voice / remote 三个密钥库，AndroidKeyStore 失败自动切软件密钥（应用沙箱保护）并在导入完成提示「按兼容模式保存」——针对卓易通等无 Keystore 容器的防御性降级。
4. **语音自检**：导入语音凭证后检测系统识别服务，不可用自动切阿里云转写并开启语音输入。
5. **联网搜索默认化**：配置包携带全局「搜索能力」开关；全局开启时新会话默认联网（人物会话仍强制关），模型或配置不支持时静默跳过（`Dropped Options: web_search`）。
6. **生活简洁模式**：开启后生活页只保留新建对话按钮与最近会话，隐藏智能体/知识库/搜索入口；开关在「我的」，可由配置包远程写入。
