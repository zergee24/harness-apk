## 产品定位

Harness APK 是一个**自用为主**的移动端个人 AI 工作台，覆盖两种真实使用模式：

- **生活模式**：知识工作流。带智能体人格的对话、离线知识包（hwiki）检索与引用，随手问答、研究与写作。
- **工作模式**：项目 + 桌面端协作。项目会话、Markdown 文件变更审核与写回、Git 状态，以及手机遥控桌面 Codex 的远程控制。

产品不定位为通用聊天应用，不追求社交、账号、云端协同或应用商店分发。**底层能力是横切的**：模型/Provider、会话引擎、智能体、Wiki 知识包、搜索/语音/技能、写回/审核、远程控制、自更新均为模式无关能力，任何会话/项目内可挂载；首页聚合为三个 Tab（生活=按会话聚合，工作=按项目聚合，我的=设置聚合）。

## 导航结构（三 Tab 底部导航，双模式叙事）

- 首页为底部三 Tab：生活 / 工作 / 我的；一次点按切换，无嵌套层级；启动恢复上次 Tab。
- 生活 Tab：仅普通会话列表（`projectId == null`，隐藏项目层级，无"按项目分组"）+ 智能体、知识库快捷入口 + 新建会话。
- 工作 Tab：远程控制入口卡片（未配对隐藏）+ 项目列表 + 项目工作台（会话/文件夹/Git）。
- 我的 Tab：设置聚合页（内嵌：Provider/搜索/语音/Git/技能/智能体包/知识库/更新/远程节点），顶栏设置按钮已移除。
- 双主题：生活=暖浅（奶油暖色、大圆角），工作/我的=深科技（石墨深色、锐利小圆角），300ms 颜色过渡，全 App 统一跟随。
- 主要能力挂载点：智能体=会话内选择人格 + 我的 Tab 全局管理；Wiki 知识包=会话内检索/引用 + 我的 Tab 库管理；远程控制=全局能力，工作 Tab 提供入口。

## 当前状态（0.2.4）

### 已具备能力

- 多会话聊天、本地保存、流式回复、图片附件、上下文压缩、联网搜索。
- 智能体体系：Agent Builder 打包人格/语料 `.hbundle`、签名校验、安装管理、删除解关联。
- 李德胜 V2 可检索智能体：5,151 页扫描书稿经 Vision OCR 文本层重建，构建并签名发布 `li-de-sheng` schema v2 `balanced` `.hbundle`（侧载导入，产物不进 Git/APK）。
- hwiki 知识包体系：双史书（二十四史/资治通鉴）离线检索、Markdown 脚注引用、证据校验、版本管理。
- 项目工作台：项目会话、Markdown 文件变更计划/审核/写回、文件预览、PDF 导出、ZIP 导入导出、Git 状态面板。
- Codex 远程控制：私有 relay/bridge、配对加密、消息确认、退避重连、审批选项。
- 三 Tab 底部导航与双主题（0.2.4，测试通道待真机验收；双模式叙事保留）。
- APK 更新检查、分片下载、校验、安装；测试/正式通道分离。

### 主要缺口（按阶段分组）

**P0 闭环（代码级）**
- 写回项目后 Git 状态不自动刷新：apply 路径只刷新会话内 deliverables，需手动跳转 Git Tab 才读 `git status`。
- 项目上下文无 UI 展示：数据与测试已就绪，但用户在会话中看不到"本轮已携带项目上下文"。
- 当前项目无常驻提示：模型有 Chip，项目名仅在配置弹窗内，主界面无提示。
- 安装取消无反馈：`ApkInstaller` fire-and-forget，用户在系统安装器取消后无任何提示。
- WORK/我的 深色主题下系统状态栏图标对比度未联动（浅色系统设备上深色状态栏图标在深色背景下不可见）。

**P0 收尾（流程）**
- 0.2.4 真机验收未完成：底部三 Tab 切换、生活 Tab 无项目分组、我的 Tab 设置聚合、双主题、重启恢复；androidTest（含重写的 Tab 导航测试）未在设备执行。
- 发布节奏未固化：积压功能曾长期停留在 test 分支（0.2.2 才第一次收口）。

**P1 生活线（补齐 agent 侧 RAG 闭环，详见 P1）**
- Agent 语料引用不可溯源：`AgentPromptContract` 主动抹掉 `[资料 N]`，来源卡为纯文本不可点（wiki 侧已可溯源）。
- Agent 语料无引用核验、无原文快照防漂移（wiki 侧已有 `WikiCitationVerifier` 与快照回退）。
- agent↔wiki 在模型层完全解耦：`Agent` 无 wiki 关联字段，所选 agent 与会话 wiki 范围互不影响。

**P2 工作线**
- Git 仍是状态查看，缺移动端 diff 摘要、低风险提交/推送确认流程。

**横切能力**
- 远程控制缺真机回归与可靠性验证（横切能力，不绑工作线，与 P3 一并维护）。

## 阶段目标

### P0：稳定可用闭环（进行中）

在真实 Android 设备上稳定完成一次完整工作流：创建/导入项目 → 新建项目会话 → LLM 生成或更新 Markdown → 审核 diff 并写回 → 文件夹查看结果 → Git 状态 → 自更新获得新版本。本阶段只定义"项目写回闭环"；三 Tab 底部导航是已交付的导航层重构（0.2.4，取代 0.2.3 双面板 Pager），单独跟踪，不并入 P0 定义。

### P1：生活模式知识工作流增强（补齐 agent 侧 RAG 闭环）

主线：以 wiki 侧成熟的 RAG 闭环为范本，**只补 agent 侧、不动 wiki**，让带人格的智能体在对话中真正用好语料与知识库。李德胜 V2 可检索智能体已交付（导入即用）。迭代骨架：

- L1 Agent 语料引用可溯源：`⟦A1⟧` token + 上标 + 来源卡可点击 + `AgentSourceReaderScreen` + deeplink，对称 wiki 体验。
- L2 Agent 引用核验 + 原文快照防漂移：对称 `WikiCitationVerifier` 与快照回退。
- L3 agent↔wiki 协同绑定：`Agent` 增加关联 wiki 字段，切换 agent 自动带入对应 wiki 范围；消解 prompt"只使用人物资产"与 wiki 证据的冲突。
- L4 检索可解释面板：把已采集的 `AgentRuntimeDiagnostics`/`WikiRetrievalRun` 渲染为"本轮检索说明"卡。

生活模式作为手机端研究与知识问答的默认入口。

### P2：工作模式项目工作台增强

项目页信息架构优化；文件夹筛选/搜索/预览；Git 面板移动端友好的 diff 摘要、提交前确认与低风险提交；项目导入导出错误提示与冲突处理。远程控制作为横切能力单独维护（见 P3），工作线只保留其入口聚合。

### P3：分发、更新与长期维护

测试/正式通道分离（已有）；发布前固定回归清单；manifest 向后兼容与强制更新；关键异常诊断与敏感信息脱敏；按版本维护已知问题与回滚说明。横切能力（远程控制、Provider、搜索、语音、技能）的可靠性回归与本阶段持续维护项一并推进，不绑任何模式线。

- 关键异常诊断信息保留，持续检查敏感信息脱敏。
- 按版本维护已知问题、修复记录与回滚说明。

## 优先级原则

1. 安全优先：API Key、项目文件、图片和 prompt 不应被误写、误传、误导出。
2. 收口优先：一条线只有跑通真机验收并发布才算完成，再开下一条；功能不长期积压在 test 分支。
3. 闭环优先：优先完成会话→文件→Git→更新的闭环，而不是横向增加入口。
4. 审核优先：任何项目文件写入、Git 提交和发布动作都需要用户确认。
5. 能力横切：模式只决定聚合视角，能力不因模式分裂、不重复建设。
6. 稳定优先：长文本、流式渲染、上下文压缩和更新下载优先避免卡顿和不可恢复失败。
7. 移动端优先：手机上只做高频、明确、低风险操作。

## 暂不做

- 用户账号、家庭成员体系和云端会话同步。
- 应用商店发布、支付、订阅和额度管理。
- 静默安装、后台无感升级和高风险系统权限。
- 自动提交、自动推送或无审核写入项目文件。
- 复杂插件执行平台和第三方代码运行。
- 完整 IDE 式代码编辑器。
