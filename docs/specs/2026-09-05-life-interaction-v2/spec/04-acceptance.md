# 生活交互 V2 · 验收用例与记录模板

2026-09-06：V2 已实现，本轮完成全量单元测试与精选设备仪器测试、真实问答/恢复走查。下方 A01–A50 仍是完整验收定义；第 6 节单列本轮已执行范围，不把一组逻辑测试等同于该 ID 的全部设备组合。准确测试数、代码提交与 APK 摘要见 [validation.md](../validation.md)。

优先级：P1 是本次交付必须通过的正确性/主链项；P2 是本轮完整 UX 的必需项，但可独立于 P1 开发。局部切片可先交付，不得将未完成 P2 的包命名为“V2 全部完成”。

验证方式：U=纯逻辑/契约；S=存储/Room migration/进程恢复；C=真实 Compose 组件组合；D=明确授权设备实测。故障注入在测试 seam 中做，不破坏真实用户数据。
