# M1 零摩擦捕获与上下文整体验收清单

验收基线：`test` 分支，M1 最终提交以实施台账为准；不要求进入设置启用语音，不要求联网完成本地搜索。

建议先准备：一个已配置可发送消息的模型、一个项目、一个智能体、两个已安装 Wiki、两张照片、一个 PDF，以及一台可用系统语音识别的 Android 真机。

## A. 输入与恢复

- [ ] **A1 空输入直接语音**：新建会话，不进入设置；输入为空且无附件时，尾部只显示麦克风。首次点击直接出现系统权限或开始识别。说一句中文后，文字进入输入框但不自动发送。
- [ ] **A2 识别结果可编辑再发送**：修改 A1 的转写文字后手动发送。会话中出现修改后的文字，不能出现未修改版本或自动发送产生的重复消息。
- [ ] **A3 单一主按钮状态**：空输入为麦克风；输入文字或选择图片后变为发送；识别中或模型生成中变为停止。尾部不能同时出现两个主操作。
- [ ] **A4 失败不丢草稿**：输入一段未发送文字，分别执行拒绝麦克风权限、旋转屏幕、切到后台再返回。文字和已选图片仍在，且没有自动发送。
- [ ] **A5 进程重建恢复草稿**：输入文字并选择一张图片，不发送；从系统强制停止 App 后重新打开同一会话。文字和图片选择可恢复。

## B. 不可变上下文

- [ ] **B1 发送上下文完整**：在项目会话中选择智能体、两个 Wiki、模型、推理强度、联网状态和一张图片后发送。展开该条用户消息的“发送上下文”，能看到项目、智能体精确版本、Wiki 精确版本、供应商/模型/强度、联网状态、附件 MIME/大小/SHA-256 与捕获时间。
- [ ] **B2 旧消息不可被改写**：B1 发送后更换智能体版本、Wiki 版本、模型或联网状态。再次查看 B1 的发送上下文，所有值仍保持发送当时的快照。
- [ ] **B3 失败原子回滚**：在无可用模型或主动制造发送前失败时点击发送。输入草稿应保留，不能出现只有用户消息却没有执行项/快照的半条记录。

## C. Android 系统分享

- [ ] **C1 浏览器 URL**：从浏览器分享一个 URL 到 AI，选择最近项目会话，再补一句文字并发送。从系统分享开始到正常发送路径不超过“选择目的地、点击发送”两次确认。
- [ ] **C2 两张相册图片**：从相册一次分享两张图片到 AI，选择最近生活会话并发送。两张图都能预览，发送后仍可打开图片预览。
- [ ] **C3 文件管理器 PDF**：从文件管理器分享 PDF 到 AI，选择最近项目。一次确认后文件进入项目 `files/`；PDF 不得自动加入会话模型上下文。
- [ ] **C4 分享进程恢复**：停留在分享目的地面板时强制停止 App，再重新打开。分享文字/图片和候选目的地仍在，不要求重新分享。
- [ ] **C5 安装包路由优先**：分别从系统文件管理器打开 `.hbundle` 和 `.hwiki`。必须进入智能体/Wiki 安装流程，不能进入普通分享目的地面板。
- [ ] **C6 分享限制与清理**：尝试分享单项超过 50 MiB、总计超过 100 MiB 或超过 10 项的文件。整批失败并给出提示，不能留下可继续发送的半批附件。

## D. 会话上下文交互

- [ ] **D1 单一上下文条**：会话输入区上方只保留一条“项目 · 智能体 · Wiki · 模型”摘要，不再出现可横向滚动的多排配置 Chip。
- [ ] **D2 上下文面板**：点击摘要后，项目、智能体、Wiki、模型、联网和上下文占用纵向可读；键盘打开和系统返回手势下，当前选中项不被遮挡。
- [ ] **D3 在其他项目继续**：在已有用户消息的会话中输入一段未发送草稿，然后切换到其他项目。系统创建新会话并携带草稿、当前智能体和已启用 Wiki；旧会话的项目归属、历史消息和 Markdown 关联不变。

## E. 本地全局搜索

- [ ] **E1 统一入口与列表**：从生活会话列表或项目工作台点击全局搜索。页面只有一个搜索框和一个混合结果列表，没有分类 Tab。
- [ ] **E2 中文消息定位**：搜索一段已有中文消息中的连续 2 至 3 个汉字。点击结果后进入正确会话、滚动到对应消息并短暂高亮。
- [ ] **E3 引用资料定位**：搜索已发送回答引用资料中的标题或原文片段。结果标记为“引用资料”，点击后定位到对应消息。
- [ ] **E4 项目定位与删除同步**：搜索项目名称可打开该项目工作台的会话页；删除消息、会话或项目后，旧结果不再出现。
- [ ] **E5 离线搜索**：关闭 Wi-Fi 和移动数据后重复 E2、E4。本地结果和定位仍正常，不出现联网提示。

## F. 极端环境与回归

- [ ] **F1 窄屏与大字体**：在约 320dp 宽、系统字体 1.3 倍下检查会话输入、上下文面板、分享目的地和全局搜索。文字不重叠、不横向溢出，主要按钮可见。
- [ ] **F2 TalkBack**：开启 TalkBack，依次浏览搜索框、搜索结果、上下文摘要和输入尾部按钮。每个操作都有可读名称，搜索结果可双击打开。
- [ ] **F3 分屏**：将 AI 放入分屏，打开会话、上下文面板和全局搜索。页面可滚动，输入框和主按钮不被裁掉或重叠。
- [ ] **F4 存储空间不足**：在测试设备空间接近耗尽时分享两个文件。写入失败后整批回滚；释放空间后可重新分享，不能看到上次失败留下的单个暂存文件。
- [ ] **F5 后台与网络切换**：模型生成中切到后台，切换 Wi-Fi/移动网络后返回。请求应继续或进入可恢复的明确状态；输入区草稿不能丢失，也不能因界面失焦主动中断。
- [ ] **F6 版本升级**：从 M1 前的 0.2.x 安装包覆盖安装当前 `test` 包。原有会话、消息、智能体、Wiki、项目和旧发送上下文都可打开，全局搜索首次进入后可搜到旧数据。
