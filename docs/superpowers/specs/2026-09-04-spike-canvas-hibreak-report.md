## 1. 结论

HiBreak 电纸书 + 自带手写笔**满足进入 P1（本地简报核心）的输入条件**：

1. 手写笔能力真实可用——压感与 tilt 均为触控硬件上报（非注入/恒定值）；
2. 墨水预览管道延迟健康（事件→绘制 p50 12~21ms / p95 22~27ms）；
3. 点级擦除、压感变宽、JSONL 追加日志、强杀恢复全部真机验证通过；
4. 书写过程手指零混入（24 笔全为 stylus，掌搭无污染）。

e-ink 面板物理刷新是"跟笔"的剩余上限，属于设备特性而非管道缺陷；缓解路径见 §4。

## 4. 跟笔（e-ink 残余风险与缓解）

事件管道健康，"不跟笔"的剩余部分来自 e-ink 面板刷新。已落地缓解：离屏位图缓存 + 局部失效（触摸只重绘笔尖矩形，触发面板局部快刷），统计条移出画布。建议叠加：

1. 系统层：Bigme 控制中心把本 App 的墨水屏刷新模式调至最快档（A2/高速）；
2. 代码层候选（P1 时再做）：笔迹预测（按速度外插一段）、压感线宽的 e-ink 抖动评估（反锯齿灰边可能拖慢刷新）。

## 5. 未覆盖项（如实记录）
