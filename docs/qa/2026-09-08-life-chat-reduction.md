# 生活与聊天交互减法

生活主屏直接打开当前问题，只在输入框中保留提示。欢迎标题和说明已删除，历史记录成为独立页面。沿用 Compose Material 3 和现有业务能力。

## 已实现

- 主屏记住当前会话，重启、切换模式、打开历史后继续原草稿；空白会话沿用历史过滤规则。新建过程中移除旧输入，避免误操作；归档后返回会打开有效会话。
- 历史页使用扁平记录行，标题旁仅显示时间，正常完成不显示徽章。页内搜索标题或摘要，区分空历史、没有匹配结果与读取失败；重命名、归档、撤销和恢复保留。
- 当前模型在普通模式顶栏出现一次；简洁模式隐藏模型名并保留智能体身份。消息详情仍可查各次发送时的模型、知识库及附件依据。
- 用户消息使用浅中性底色，普通角色标签移除，文件复用一层容器并可整项展开。追问建议进入回答更多，仍先填入草稿，不自动发送。
- 输入区使用一个容器，附件和说话在左、发送或停止在右。保留语音录音、转写、预览与确认流程，处理键盘避让和系统字号。
- 切页前复用草稿保存流程，保存失败仍提供重试、留页和放弃修改；待确认发送仍查询原请求，不自动重发。
